# 🔐 Password Generator App

A modern, secure, and customizable **Password Generator** built using **Next.js**, **TypeScript**, and **Tailwind CSS**. This app allows users to generate strong passwords based on their preferred criteria such as length, character types, and more.

## 🚀 Features

- ✅ **Customizable Options**
  - Include uppercase letters
  - Include lowercase letters
  - Include numbers
  - Include special characters
  - Set desired password length

- ⚡ **Instant Generation**
  - Generates a password in real-time as per user-selected options

- 📋 **Copy to Clipboard**
  - One-click copy functionality

- 🎨 **Responsive Design**
  - Mobile-friendly and clean UI using Tailwind CSS

- 🔒 **Secure Logic**
  - Built-in logic ensures strong and random password generation
